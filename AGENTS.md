# Project guidance

- Preserve “Created by Nikeel Naidoo” and the creator/concept-owner credit.
- Preserve unrelated work. Never commit credentials or private keys.
- The user prefers economical, sequential work. Do not start extra agents, scheduled automations, background monitoring or repeated checks unless the user requests them or they are necessary for the current task.
- Run focused checks when code changes require them. Avoid persistent test watchers. Stop task-owned development servers and other idle processes when finished.
- Do not claim that reducing background activity changes account quotas, token allowances or reset windows.
- Keep the no-service demo playable and keep private player submissions out of public snapshots.
